# Global Lab Booking

عايزين نعمل لاندينج بيدج لمعامل جلوبال لاب عايزها موشن و بروفيشنال جدا و مليانه حركه و موشن و شغل عالي 

مختصه ب حجز التحاليل في معامل جلوبال لاب تكون صفحة تحمل هوية بصرية خاصة ب معمل جلوبال لاب و انا رفعت ليك لوجو جلوبال لاب عايز اللاندينج بيدج تكون موحدة و متناسقة مع الهوية البصرية للمعمل 

هتكون مخصصه ل حجز التحاليل داخل معامل جلوبال لاب الصورة الي انا بعتها ليك
